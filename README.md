# Hello World website

A 3-page static website with a shared design.

## Files
- `index.html` — home page (also available as `hello-world.html`)
- `about.html` — about page
- `contact.html` — contact page with a message-copy demo
- `styles.css` — shared styles
- `script.js` — interactive buttons and contact form

## Run
Open `index.html` in a browser or use the VS Code Live Server extension.

## GitHub Pages
Push these files to your repository. In GitHub repository Settings → Pages, deploy from your `main` branch and `/ (root)` folder.

**Contact form note:** The form does not send or save messages. It copies the prepared message to the clipboard (or offers text to copy). To receive submissions, connect a backend or form service.
